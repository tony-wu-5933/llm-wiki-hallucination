# 為什麼要在意幻覺

## 現實中的後果

IBM 舉出的影響：

- **醫療**：醫療 AI 可能產生偽陽性，例如把良性的皮膚病灶判斷為惡性，導致不必要的醫療處置。
- **假訊息擴散**：如果新聞機器人在緊急事件發生時，回答了未經查證的資訊，可能迅速散布錯誤訊息，干擾救災與應變。
- IBM 也提到，工程師把幻覺視為仍在研究中的問題，也是 AI 在醫療、金融、法律與法規等高風險領域可靠部署的主要障礙。

Ji et al. 舉出的影響：

- **醫療**：由病患資料表產生的摘要若有幻覺，可能對病患造成風險；機器翻譯的藥物說明若有幻覺，可能引發危及生命的事件。
- **隱私**：有研究顯示，語言模型可能被誘導還原並產生訓練資料中的個人敏感資訊（例如 email、電話、地址）。Ji et al. 把這也視為一種幻覺，因為這些資訊不在輸入來源中。

## Agent 會把幻覺放大：Cascading hallucination

IBM 指出，自主 AI agent 越來越普及，可能放大幻覺的影響。在多個 agent 或多個步驟串接的流程中，一個幻覺可能成為後續步驟的前提，下游的每個 agent 都把它當成已驗證的事實：

> Agent A 捏造一個錯誤 → Agent B 依據這個錯誤檢索或推理 → Agent C 摘要 B 的輸出 → 最後產出一個包裝完整、看似前後一致，但前提是錯的答案。

結果常常形成連鎖幻覺（cascading hallucination）：後面的 agent 不只是重複錯誤，還會在上面建立更多推理。IBM 的假設情境見 [[examples]]（多 agent 誤刪備份）。
